## Featured projects


- **[python-web-scraping-toolkit](https://github.com/anshumannkaushik/python-web-scraping-toolkit)** — Production scraping pipelines I use daily: parallel DuckDuckGo-based URL finders that match spreadsheet records to live Booking.com / Expedia property pages, plus a live-page fetcher that reads the real property name and address (schema.org microdata) while working around bot walls via regional mirrors. Checkpointed and resumable — built for batches of 1,000+ records.
- **[hotel-record-matching](https://github.com/anshumannkaushik/hotel-record-matching)** — Record-pair verdict engine (Same / Bad Match / Review) for hotel deduplication: name/address normalisation, fuzzy scoring, postal-code rules, an address-first verdict rule, and online cross-verification for the pairs offline scoring can't settle. Built over thousands of real pairs.
- **[supplier-product-finder](https://github.com/anshumannkaushik/supplier-product-finder)** — Finds product URLs on supplier sites (HD Supply, Zoro, Ferguson) for brand + model spreadsheets, returning a URL only on an exact part-number match verified on the product page (schema.org JSON-LD), with brand-alias handling.
- **[android-tv-apps](https://github.com/anshumannkaushik/android-tv-apps)** — Hand-built Android TV apps (no Android Studio — compiled with aapt2 + javac + d8 + apksigner): a fullscreen WebView streaming app with injected D-pad spatial navigation, and a launcher shortcut app.
- **Browser automation extensions** — Firefox WebExtensions for bulk data operations: [Site Counter](https://github.com/anshumannkaushik/site-counter-extension) (cross-tab site counting), [Bulk Unlink Manager](https://github.com/anshumannkaushik/bulk-unlink-manager) (one-click bulk unlink across ~300 open tabs), and [Smart Autofill](https://github.com/anshumannkaushik/smart-autofill-extension) (spreadsheet-driven form autofill).
